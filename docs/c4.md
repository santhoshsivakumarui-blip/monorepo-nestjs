# C4 overview

```text
Clients -> API Gateway -> Users / Orders / Notifications
                       |       |         |
                    Redis   Postgres    RabbitMQ
                       \       |       /
                            Kafka -> Elasticsearch projection
```

The gateway owns external HTTP policy. Domain services own business rules and databases. Kafka distributes domain facts; RabbitMQ dispatches notification work; Elasticsearch supports read/search projections.
